# Expense Management System

## Overview
A menu-driven Expense Management System developed using Python and CSV file handling. The application allows users to record expenses, view stored records, search by category, and generate monthly expense reports.

## Features
- Record Expense
- Display Expenses
- Search by Category
- Monthly Report
- CSV File Storage

## Technologies Used
- Python 3
- CSV Module
- Datetime Module
- File Handling

## How to Run
1. Open the project in PyCharm.
2. Run expense_tracker.py.
3. Select menu options as required.
